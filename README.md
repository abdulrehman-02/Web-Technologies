# UMT Login Page

A simple HTML login page inspired by the University of Management and Technology (UMT) student portal interface.

## Overview

This project recreates the basic structure of a university portal login page as a frontend practice project. It focuses on HTML structure, form elements, layout, and basic webpage styling.

## Features

- Username and password fields
- Remember username option
- Login button
- Password recovery link
- UMT inspired background and branding

## Technologies

- HTML5
- Inline CSS
